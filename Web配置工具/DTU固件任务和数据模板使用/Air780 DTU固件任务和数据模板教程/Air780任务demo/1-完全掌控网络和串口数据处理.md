# 一、功能描述

​	本实例实现完全截取网络数据和串口数据一个基本框架。

​	停止内部处理网络数据和串口数据，交给任务去处理，定义自己的逻辑

​	收到数据后，自己去做校验，处理数据，并且发送到需要发送的地方(可以实现不同串口，不同网络通道之间数据流转)

​	1、通过PronetGetRecChAndDel(nid) 获取是否有收到网络数据，如果有网络数据处理网络数据

​	2、判断nets是否有数据,如果有数据 调用PronetSetSendCh(nid,nets) 让网络通道发数据

​	3、通过UartGetRecChAndDel(uid) 获取对应串口是否有收到数据，如果收到处理串口数据

​	4、判断uarts是否有数据,如果有数据，调用UartSetSendCh(uid,uarts)给串口发数据



​        注意这个架构很简单，很重要，全部的任务的根本都是这4个API+扩展API完成各种各样的功能。多通道的转发，数据的处理，解析，重新组装打包。

# 二、代码

```lua
function
	local taskname="userDataTask"
	log.info(taskname,"start")
	local nid=1
	local uid=1
	PronetStopProRecCh(1)
	UartStopProRecCh(1)
	while true do
		local netr = PronetGetRecChAndDel(nid)
		if netr then 
			log.info(taskname,"netr data",netr)
			
		end
		
		local nets=nil
		if nets then 
			if 1==PronetGetNetSta(nid) then 
					PronetSetSendCh(nid,nets)
				end 
		end
		
		local uartr=UartGetRecChAndDel(uid)
		if uartr then 
			log.info(taskname,"uartr data",uartr)
		end 
		
		local uarts =nil 
		if uarts then 
			UartSetSendCh(uid,uarts)
		end 
		sys.wait(5000)
	end
end
```
