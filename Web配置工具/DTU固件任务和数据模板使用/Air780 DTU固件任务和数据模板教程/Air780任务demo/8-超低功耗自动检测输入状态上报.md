# 一、功能描述

使用场景是10分钟以上定时周期采集数据，本demo使用YED-D780L2Y 作为demo，D780L2Y 是电池供电,所以用PerGetVbattV 函数的读出来的就是电池电压。

一般的传感器上电后需要延迟一段时间后才能采集数据，电流采集一般等信号稳定了在采集,可以多次采集后求平均值。

如果输入IN1和IN2 主动变换了会主动唤醒设备上报数据。

注意如果过快进入低功耗，可能会导致DTU更新不了参数(还没更新参数，DTU就休眠了,如果后续要更新参数需要预留住够的时间)。

# 二、代码

```lua
function 
	mobile.flymode(0, false)
	local taskname="userTask"
	log.info(taskname,"start")
	local nid=1
	local count =0
	local netsta =0
	PerCtlPowerOut(1)
	while count < 60 do 
		netsta = PronetGetNetSta(nid)
		if netsta ==1 then 
			break
		end 
		count =count +1
		sys.wait(1000)
	end 
	sys.wait(10000)
	local d ={}
	d.datetime=os.date("%Y-%m-%d %H:%M:%S")
	d.csq=mobile.csq()
	d.sn=mobile.imei()
	d.iccid = PerGetIccid()
	d.vbat = PerGetVbattV()
	d.In1 = PerGetDiById(1)
	d.In2 = PerGetDiById(2)
	d.A1=PerGetAdcGatherValByAdcId(0)
	d.A2=PerGetAdcGatherValByAdcId(1)
	PerCtlPowerOut(0)
	local updata = json.encode(d)
	netsta = PronetGetNetSta(nid)
	log.info(taskname,"updata",updata,"netsta",netsta)
	if updata and netsta ==1 then 
		PronetSetSendCh(nid,updata)
	end
	sys.wait(5000)
	SysNeedInSuperPower()
	log.info(taskname,"superlowpower")
	SysInSuperLowPower(600)--老Air780E用这个，air780EP,Air780EPM的重新封装
end
```
