```lua

--例如 local function test()     end
--注意函数头尾不要留有空格

```

![img](https://cdn.nlark.com/yuque/0/2025/png/42958080/1739951613827-f2db678b-033c-47cf-904c-8b2ab72e4590.png?x-oss-process=image%2Fwatermark%2Ctype_d3F5LW1pY3JvaGVp%2Csize_34%2Ctext_eWluZXJkYQ%3D%3D%2Ccolor_FFFFFF%2Cshadow_50%2Ct_80%2Cg_se%2Cx_10%2Cy_10)

## 4.3、添加日志方法

在任务里面使用log.info()函数打印日志，可以打印字符串，原始数据或者hex形式的字符串。大部分调试Modbus协议的设备，都是打印Hex形式的字符串，而不是Hex原始数据，因为Hex数据会显示乱码。比如可以把下列代码拷贝到任务里面看现象。

```lua
function
  local taskname="usertask "
  log.info(taskname,"start")
  while true do 
      local str="json test"
      log.info(taskname,"str=",str)
      local hex=string.char(0x01,0x03,0xaa,0xbb,0xcc)--模拟modbus的 hex原始数据，打印是乱码
      log.info(taskname,"hex=",hex)
      local hex_string=string.toHex(hex) --hex转可显示的hex 字符串
      log.info(taskname,"hex_string=",hex_string)
      sys.wait(2000)
  end 
end
```

更新参数后，可以看到luatool 2秒周期打印数据日志。

可以看到第2句的hex是显示的乱码，无法显示hex数据，用第3句就可以现在HEX，这个方法在调试modbus数据很重要。
