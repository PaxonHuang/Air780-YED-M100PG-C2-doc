# 一、简介

变量，格式如${XXX},是DTU参数的一个占位符号，在DTU逻辑会自动把它匹配成设备运行的实际值，用来实现批量自动替换的功能。

变量分为通用变量和专用变量。

通用变量在全部的字符串模式下都能匹配，比如${IMEI},${ICCID}，${GPS},${LBSLON},${GPSLONT}等；专用变量只有特定功能应用.。

# 二、使用场景

使用场景一:

  在分组里面定义MQTTtopic的时候，可以写成/xxx/${IMEI},设备就会自动把${IMEI}替换成模组的实际值,如86514568912345，设备真实的topic是/xxx/86514568912345，达到自动匹配的目的。

使用场景二:

  变量可以在字符串里面自由组合，可以组成json给格式，比如在心跳包里面设置心跳数据

{"IMEI":${IMEI},"dingwei":${GPS}}

# 三、注意事项

1、变量引用都是字符串格式的，不是整数和浮点函数

2、变量只能用在配置界面的字符串模式，比如心跳包，注册包，定位上报,MQTT topic等地方。不能用在任务和数据模板里面。

3、一句话里面同一个变量如果出现多次，只会匹配第一次出现的位置，其他地方的变量不能匹配。

# 四、变量

| 变量名     | 功能             | 通用/专用 | 说明                                                         |
| ---------- | ---------------- | --------- | ------------------------------------------------------------ |
| ${IMEI}    | 模组IMEI         | 通用      | 都支持                                                       |
| ${IMSI}    | SIM卡IMSI        | 通用      | 都支持                                                       |
| ${ICCID}   | SIM卡ICCID       | 通用      | 都支持                                                       |
| ${CSQ}     | 信号强度         | 通用      | 都支持                                                       |
| ${GPS}     | 基站定位固定格式 | 通用      | 都支持                                                       |
| ${LBSLON}  | 基站经度         | 通用      | 都支持                                                       |
| ${LBSLAT}  | 基站纬度         | 通用      | 都支持                                                       |
| ${GPSLONT} | GPS经度东西      | 通用      | 都支持                                                       |
| ${GPSLON}  | GPS经度          | 通用      | 都支持                                                       |
| ${GPSLATT} | GPS纬度南北      | 通用      | 都支持                                                       |
| ${GPSLAT}  | GPS纬度          | 通用      | 都支持                                                       |
| ${TIMEM}   | 时间戳           | 通用      | 都支持,Air724内部是os.time()*1000 单位msAir780内部是os.time() 单位秒 |
| ${RN}      | 回车换行\r\n     | 通用      | 目前780方案支持                                              |
| ${DIn}     | 数字量输入通道   | 专用      | 目前724方案支持                                              |
| ${AIIn}    | 电流量输入通道   | 专用      | 目前724方案支持                                              |
| ${AIVn}    | 电压量输入通道   | 专用      | 目前724方案支持                                              |
| ${NUM}     | 短信电话号码     | 专用      | 目前780方案支持                                              |
| ${TXTH}    | 短信原始数据     | 专用      | 目前780方案支持                                              |
| ${TXTS}    | 短信字符串       | 专用      | 目前780方案支持                                              |
