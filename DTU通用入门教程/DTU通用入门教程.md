# 一、简介

银尔达DTU固件支持WEB平台批量配置参数，配置平台: https://dtu.yinerda.com

# 二、优点

相对于传统的PC配置有以下显著优点:

1)可批量

​    如果设备的参数相同，创建分组，只需要配置一次参数，后续设备直接加入这个分组就可以自动获取，节省时间；

2)可修改

   如果设备已经部署出去了，后续想通过服务器等参数，可以远程重新设置参数，设备重启后就会自动更新；

3)可追溯

   每台设备的参数可以保存，设备什么时候请求了参数服务器；

4)可记录SIM卡

   可以方便客户管理SIM卡，防止SIM卡过期；

5)可控

   用户如果不想WEB配置，可以配置后，关闭WEB配置，设备就永远不会请求参数服务器，和传统的串口配置参数方法一样；

6)数据不过配置平台

配置平台只是配置设备参数，设备通过HTTP方式请求服务器

# 三、缺点

WEB 平台不配置内网卡的设备，需要先插公网卡，获取参数后才能安装专网或者内网卡正常使用；也可以通过PC串口配置。



# 四、注意事项

如果你使用的定向卡，需要添加DTU用到的域名信息，SIM卡才能访问配置服务器。把下列数据提交到SIM卡供应商即可，供应商给您添加到白名单即可。

银尔达提供的SIM卡，都是普通卡，不需要添加这些域名。

| dtu.yinerda.com       | 91   | HTTP | WEB参数配置                     | 是       |

| bs.openluat.com       | 80   | HTTP | WIFI/基站定位平台，基站定位需要 | 否       |
| download.openluat.com | 80   | HTTP | AGPS星历下载平台，GPS定位需要   | 否       |
