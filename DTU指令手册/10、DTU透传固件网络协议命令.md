# 特殊说明1

固件升级原因，会导致老固件不支持新功能，如果需要新功能，需要升最新固件测试；

由于固件开发不同步原因，Air724和Air780对命令支持度不相同，具体命令有适用性说明。

# 特殊说明2

网络网络通道随着固件的升级，协议也在升级。新版本的固件可能比老版本的参数更多，程序设计了兼容，新老命令都可以用，只是新升级功能无效。

一般来讲，DTU只需要设置网络通道参数命令，很少需要网络通道参数命令。

# 6、MQTT协议命令-mqtt

# 7、HTTP协议命令-http

请求实际地址是服务器地址:端口/Url。如果使用Get协议，串口发送的数据直接拼接到了实际地址的后面。所以数据需要符合http rul编码规范(可以百度一下)，要不然无法传送。
