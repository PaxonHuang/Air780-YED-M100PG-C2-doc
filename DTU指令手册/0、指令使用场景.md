# 一、使用场景

1、把命令集成到MCU，用MCU配置DTU功能。

2、MCU通过命令查询设备IMEI，读取信号强度等。

3、服务器需要远程查询设备参数或者控制硬件资源，比如控制继电器开关，查询输入状态等

# 二、注意事项

1、2条命令之间最少间隔2-3秒发送，否则可能会粘连数据，数据透传到服务器。

2、基站定位命令，耗时最长60秒，其他命令基本1秒内能回复。

3、不要频繁去发命令控制查询设备，避免过影响正常设备通讯。

4、如果参数源设置成WEB或者WEB和串口。如果这些模块如果被分配到WEB配置系统，并且有新参数，会覆盖模块本身的参数。

# 三、建议

如果是参数配置，建议优先使用WEB配置，如果不能用WEB配置的考虑用指令配置。Air780系列还可以用专门的PC配置软件配置参数。
