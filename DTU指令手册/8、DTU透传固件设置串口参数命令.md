# 特殊说明1

DTU串口有TTL，RS232，RS485等接口。由于历史原因，串口配置命令有多种名称设置。

如果用ttluart配置TTL串口的时候返回error，可以换成uart试试。如果用rs232配置RS232串口的时候返回error，可以换成uart试试。

| 硬件串口 | 程序名字1 | 程序名字2 |
| -------- | --------- | --------- |
| TTL      | ttluart   | uart      |
| TTL-2    | ttluart_2 | uart_2    |
| RS232    | rs232     | uart      |
| RS485    | rs485     |           |
| RS485-2  | rs485_2   |           |
| RS485-3  | rs485_3   |           |

# 特殊说明2

Air724不支持7位数据；Air780支持7位数据；

# 特殊说明3

Air724 RS485 EN 默认是0，如果出现丢数据的时候，可以设置成1,1是最快的。

Air780 RS485 EN 默认是0，如果出现丢数据的时候，115200波特率，设置成0可以用，如果是其他波特率，设置成5000~20000 根据具体设备调试，直到不丢失数据为止

# 特殊说明4

YED-D780L2-Y的RS485 EN 是硬件自动反转的，可以解决EN反转慢的问题，但是波特率最高9600

# 1、设置ttl串口参数命令-ttluart

| 功能     | 设置ttl串口波特率出厂值默认115200,8位数据，无校验，1位停止位 |                                                              |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 设置参数 | 参数                                                         | 描述                                                         |
|          | 波特率                                                       | 1200~921600                                                  |
|          | 数据位                                                       | 7:7位8:8位                                                   |
|          | 校验位                                                       | 0:无检验1:奇校验2:偶校验                                     |
|          | 停止位                                                       | 1:1位2:2位                                                   |
|          | 分包超时时间                                                 | 串口分帧超时时间，单位ms；超时时间内收到新数据，顺延超时时间，直到超时后没数据收到后发送出去 |
|          | EN翻转延迟                                                   | 固定0；目前无效，做兼容占位                                  |
| 返回参数 | 无                                                           |                                                              |
| 设置实例 | config,set,ttluart,9600,8,0,1,80\r\n\r\nconfig,ttluart,ok\r\n |                                                              |
| 查询参数 | 无                                                           |                                                              |
| 返回参数 | 与设置参数相同                                               |                                                              |
| 查询实例 | config,get,ttluart\r\n\r\nconfig,ttluart,ok,9600,8,0,1,80,0\r\n |                                                              |
