# 1、单次HTTP Get请求命令-httpget

| 功能     | 单次执行HTTP get命令。 如果有返回返回数据，如果错误返回错误码。一般用来使用HTTP请求一些参数信息，然后使用串口把获取的信息配置4G模块的连接参数。 |      |
| -------- | ------------------------------------------------------------ | ---- |
| 获取参数 | HTTP请求地址，包含域名，端口，地址和参数                     |      |
| 返回参数 | 服务器数据或者错误码                                         |      |
| 读取实例 | config,get,httpget,http://test.yinerda.com:1000/a631ae9939838faf2e435f9c1f0fde57\r\n\r\nconfig,httpget,error,-8\r\n |      |
| 注意     | 网络超时最长10秒，最长10秒返回结果url自己按HTTP GET协议进行编排数据，设备不做任何转换直接使用url支持变量，支持${IMEI},${ICCID}等不支持heard设置 |      |
