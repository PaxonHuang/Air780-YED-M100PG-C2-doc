# 特殊说明1

定位功能可以简单用串口读取定位信息。但是大部分引用场景是DTU自动上报坐标信息到服务器。

自动上报可以上报简单的定位格式。如果需要详细的，复杂格式的，低功耗场景的使用任务的方式上报最方便。

# 特殊说明2

基站定位偏差大，也可能失败无法定位；GPS定位需要室外定位，具体可以百度定位原理

# 特殊说明3

Air780系列支持WIFI定位，WIFI+基站定位，能提高室内定位精度，前提附近要有WIFI才行。

# 1、设置定位数据上报命令-location

如果是用串口配置，需要用本命令开启基站定位或者GPS定位功能。

基站定位如果不开启这个功能，会卡顿，最长超时60秒；GPS如果不开启，无法获取定位。

| 功能     | 设置定位数据上报，支持基站设置和GPS设置(需要支持GPS才有效)   |                                                              |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 设置参数 | 参数                                                         | 描述                                                         |
|          | 定位类型                                                     | 1:基站定位2:GPS定位                                          |
|          | 是否开启                                                     | 0:关闭1:开启                                                 |
|          | 定位数据更新周期                                             | 单位秒                                                       |
|          | 上报数据类型                                                 | 0:不上报1:固定格式,”经度_纬度”2:自定义格式                   |
|          | 上报内容                                                     | 上报数据类型为2有效，其他用0站位。支持传类型可以应用${XXX}变量 |
|          | 上报网络通道                                                 | 网络通道ID                                                   |
|          | 付费模式                                                     | 0:免费1:付费基站模式，Air780EPM方案，V2.0.3及其后面支持付费的支持多基站联合定位和WIFI定位，更精确；免的只支持单基站定位。 |
| 返回参数 | 无                                                           |                                                              |
| 设置实例 | config,set,location,2,1,60,2,test${GPSLON}:${GPSLAT},1\r\n\r\nconfig,location,ok\r\n |                                                              |
| 查询参数 | 参数                                                         | 描述                                                         |
|          | 定位类型                                                     | 1:基站定位2:GPS定位                                          |
| 返回参数 | 与设置参数一致                                               |                                                              |
| 查询实例 | config,get,location,1\r\n\r\nconfig,location,ok,0,0,0,0,0\r\n |                                                              |

# 2、基站定位命令-lbsloc

| 功能     | 读取基站定位；前提是设备能够联网才能获取，4G基站在信息服务器能够查询。受基站密度影响，城市定位精度500M，偏远地区可能几公里。命令最长超时时间60秒。远程服务器获取基站定位的时候，需要执行location命令开启定位自动更新功能没否则会导致服务器异常。注意，可能定位失败，可以百度基站定位原理。 |                               |
| -------- | ------------------------------------------------------------ | ----------------------------- |
|          | 参数                                                         | 描述                          |
| 查询参数 | 无                                                           | 3位整数，7位小数；WGS84坐标系 |
| 返回参数 | 经度、纬度                                                   |                               |
| 设置实例 | config,get,lbsloc\r\n\r\nconfig,lbsloc,ok,110.1234567,020.1234567\r\n |                               |

# 3、获取GPS定位命令-gps

| 功能     | 读取GPS定位(需要支持GPS才行)使用之前，location命令打开GPSGPS需要在室外，空旷的地方定位，室内无法定位，具体可以百度定位原理 |                                                              |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
|          | 参数                                                         | 描述                                                         |
| 查询参数 | 无                                                           | WGS84坐标系GPS数据不能直接用在地图上，有偏差，需要纠偏纠偏方法:http://old.openluat.com/GPS-Offset.html |
| 返回参数 | 经度类型，经度、纬度类型，纬度                               |                                                              |
| 设置实例 | config,get,gps\r\n\r\nconfig,gps,ok,E,110.1234567,N,20.1234567\r\n |                                                              |
